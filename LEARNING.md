# Programming foundations and learning history

These collections record programming practice. Book/course foundations should be attributed where applicable; introductory work remains separate from claims of independent security engineering or research.

## Python

- [Python foundations](https://github.com/nix-daemon/python_practice): syntax, functions, classes, file I/O, tests, and Pygame exercises.
- [Automate the Boring Stuff exercises](https://github.com/nix-daemon/automate_boring_stuff): introductory book exercises.
- [Python utilities and projects](https://github.com/nix-daemon/python_projects): contains both practical prototypes and learning projects; its index distinguishes them.
